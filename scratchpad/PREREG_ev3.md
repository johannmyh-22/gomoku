# 预登记：评估函数敏感度诊断（活三权重 ±30%）

**本文件必须在任何 A/B 数据产生之前提交**（提交哈希即时间戳），事后不得修改判定口径。
上一轮 `PREREG_mateplykeep.md` 建立了这套流程：第一轮 48 局曾打出 +1.44σ 很诱人，
预登记的 200 局把它按回 −0.07σ。**规则先行，是这个项目唯一挡得住 p-hacking 的东西。**

---

## 1. 为什么做这个实验

PROGRESS「一之七」用三组预算实测钉死了两条：

- **测量台是好的**（50 局测出 −159 Elo，p=0.003）
- **LV5 棋力在每手约 2.25 秒饱和**，时间乘 2 / 除 4 棋力都不动

第二条划掉了一整类方向（`deeppartial`、aspiration window、counter-move、null move ——
它们的收益机制都是「同样时间搜得更深」）。**评估函数是唯一没被证伪的方向。**

但在调权重之前必须先回答更前置的问题：**权重到底是不是杠杆？**
若连大幅扰动都测不出棋力差异，那么细调权重必然也测不出，得换更大的思路
（开局库、或引入现在没有的特征）。

## 2. 假设

> **H1**：活三权重在 ±30% 范围内的改变，会造成可测量的棋力差异。
> **H0**：不会。

## 3. 被测改动（已实现，`load.js` 的 `ev3hi` / `ev3lo`）

权重表（`index.html:422`）：

```
PSCORE = [0, 2, 14, 20, 220, 240, 3000, 20000]
          无 活二 眠三? 眠三 活三 冲四 活四   五
```

| 变体 | 活三权重 | 说明 |
|---|---|---|
| `ev3hi` | 220 → **286**（+30%） | 活三**压过**冲四(240) |
| `ev3lo` | 220 → **154**（−30%） | 活三**低于**冲四(240) |

**为什么挑活三、为什么是这两个值**：

1. 整体缩放全表是纯空操作（分数只用来比大小），必须动**相对**权重，即某个单项。
2. 活三在中局几乎每手都出现，是安静局面里评估分的主要来源。
3. 邻居是冲四=240，±30% 后分别跨过这条线 —— **是质变不是微调**，
   最大化「若权重是杠杆则一定显形」的概率。

**对打方式：`ev3hi` 直接对打 `ev3lo`，不是各自 vs 出厂。** 60% 跨度，单次实验拿到
最大对比度。这是诊断而非候选改动 —— 目的是测「敏感度」，不是选一个更好的权重。

## 5. 实验设计（跑之前定死，不得事后更改）

| 项 | 值 |
|---|---|
| 档位 | **LV3 出厂配置**，逐项照抄 `LEVELS[3]`（硬规矩之二） |
| 局数 | **200 局**（100 个随机开局 × 2 次换边），固定，不得增减 |
| 开局种子 | **20260816**（全新种子；已用过的 20260811~20260815 一律不得复用） |
| 对照 | `orig` vs `orig2` 12 局，**必须精确 6:6** |
| 分块 | 4 块 × 25 开局（下标 [0,25) [25,50) [50,75) [75,100)），边界事先定死、与数据无关 |
| 落盘 | `runs/ev3_lv3_c1~c4.jsonl`，含胜负字段与 `job.id`（断点续跑） |
| 判定量 | `ev3hi` 的胜率与 z 值（和棋不计入分母） |

**为什么选 LV3 做首轮筛查**：它是真实出厂档（不违反硬规矩二）、约 13.8s/局
（LV5 的十几分之一），而且**搜得浅 → 更依赖评估**，敏感度理应最先在这里显形。

## 6. 判定规则（**先写死**）

设分胜负局数 N，`ev3hi` 胜 W，z = (W − N/2) / (√N / 2)。

| 结果 | 判定 | 下一步 |
|---|---|---|
| **\|z\| ≥ 2** | **权重是杠杆** | 进 LV5 复核（另立预登记），再谈调权重方向 |
| **\|z\| < 2** | **未能证明敏感** | 见下 |

`|z| < 2` 时的结论必须这样表述（**不得**说成「权重无关紧要」）：

> 在 LV3、200 局的分辨力下，活三权重 60% 的跨度**测不出棋力差异**。

并给出 95% 置信区间。是否再投 LV5 的算力，由 LV3 的**点估计与 CI** 决定，
规则同样先写死：

- 若 CI 上界仍容得下 ≥ +50 Elo → 值得去 LV5 再看（浅档不敏感不代表深档不敏感）
- 若 CI 已把 ±50 Elo 排除 → **评估权重不是杠杆**，结案，转开局库 / 新特征

5. 对照不是 6:6 则**整轮作废**，先查随机源，不得带着脏台子解读结果。
