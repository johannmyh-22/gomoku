# 预登记：评估轴的阳性对照（压平整张棋型权重表）

**本文件必须在任何 A/B 数据产生之前提交。** 流程出处见 `PREREG_mateplykeep.md`。

---

## 1. 为什么做这个实验

`PREREG_ev3.md` 的结果：LV3、200 局，活三权重 ±30%（60% 跨度）= **94:106，z=−0.85σ**，
未能证明敏感。**这个 null 有两种完全不同的解释**：

1. 权重表**是**杠杆，只是 ±30% 的扰动太小，没超过 200 局的分辨力；
2. 权重表**根本不是**杠杆 —— 棋力几乎全部来自 VCF/VCT 算杀那层，评估只是摆设。

两种解释导向完全相反的行动（继续投算力精调 vs 整条路封死），所以必须先分清。

**方法照搬 PROGRESS「一之七」**：那次怀疑测量台失灵，就用「预算翻倍/减半」这种
**已知该有明显效果**的改动做阳性对照。这次怀疑的是评估轴本身，就用
**大幅破坏评估**去验它。破坏比改进便宜 —— 与「减预算比加预算便宜」是同一条方法论。

## 2. 假设

> **H1**：抽掉棋型权重的全部区分度，会造成**可测量的棋力下降**。
> **H0**：不会 —— 即棋型权重表对棋力没有可测量的贡献。

注意本实验的**期望方向是负的**：这是阳性对照，`evflat` 应该明显更弱。
**测不出下降**才是那个有杀伤力的结果。

## 3. 被测改动（`load.js` 的 `evflat`）

```
出厂   PSCORE = [0, 2, 14, 20, 220, 240, 3000, 20000]
evflat PSCORE = [0, 10, 10, 10, 10,  10,   10,    10]
                 无 活二 眠三? 眠三 活三 冲四 活四   五
```

所有非空棋型同分。效果：

- `evaluate()` 退化成「我方有棋型的方向数 − 对方的」，**棋型好坏的知识全部消失**
- `SB`/`SW` 里 `s` 那条回退路径同样退化成纯连接性计数（**走法排序也一起变差**）
- 但 `SC_FIVE`/`SC_OFOUR`/`SC_44`/`SC_43`/`SC_33` 这些**战术复合判定不受影响**，
  VCF/VCT 算杀能力**完整保留**

这正好把「棋型知识」与「算杀能力」切开，回答的是：**这台引擎的棋力有多少来自评估、
多少来自算杀。**

## 4. 前置门槛（已通过）

**非空操作验证**：LV3 三个开局，`evflat` vs `orig` 全部不同，首次分歧在**第 3~5 手**。
（附带观察：平均手数 55 → 32，对局明显变短。这是先兆，**不作为证据**，判定只看比分。）

## 6. 判定规则（**先写死，按单侧分别写** —— 上一轮的规则默认 CI 对称，栽了）

设分胜负 N 局，`evflat` 胜 W，z = (W − N/2)/(√N/2)。

| 结果 | 判定 | 下一步 |
|---|---|---|
| **z ≤ −2** | **评估轴是活的**：破坏棋型知识确实掉棋力 | 解释 (1) 成立。权重可调，值得去 LV5 精调；`ev3` 那轮的 null 归因于「±30% 太小」 |
| **\|z\| < 2** | **评估权重表不是杠杆** | 解释 (2) 成立。**调权重整条路封死**，转开局库 / 新特征 |
| **z ≥ +2** | 荒谬结果（破坏评估反而更强） | 不得当成收益。说明评估表当前取值可能是**有害**的，或还有别的缺陷，需先查清再谈 |

`|z| < 2` 时的表述必须是：

> 抽掉全部棋型权重区分度后，在 LV3、200 局的分辨力下**测不出棋力差异**；
> 该引擎的可测棋力主要来自 VCF/VCT 算杀层，而非评估函数。

并给出 95% CI。

## 7. 禁止操作

1. **不得**因为结果不合预期就追加局数。200 局就是 200 局。
2. **不得**事后更改判定阈值、改单双侧、或改判定量。
3. **不得**换开局重跑后与本轮合并统计。
4. **不得**把「对局变短」「机制上说得通」当作证据 —— 判定只看比分与 z。
5. 对照不是 6:6 则**整轮作废**。
